# Иллюстрации к конспекту

Все схемы — редактируемый TikZ. Общие стили `gi ...` и неплавающее окружение
`graphillustration` определены в `config.tex`. Рёбра паросочетания — толстые синие
(`gi match`), свободные вершины — двойной серый контур (`gi free`). Цвета рёберных
раскрасок дублируются типом линии: цвет 1 — сплошная (`gi c1`), цвет 2 — штриховая
(`gi c2`), цвет 3 — пунктирная (`gi c3`).

Имена файлов начинаются с номера билета; `notation-*` относится к обозначениям.

| Исходник | Содержание |
|---|---|

| `01-symdiff.tex` | Компоненты $M\triangle M'$: чётный цикл, чётный путь и нечётный путь — $M$-дополняющий. |
| `01-augment.tex` | Инверсия дополняющего пути увеличивает паросочетание на 1. |
| `02-konig.tex` | Множества $U_i,Y_i,Z_i$ из доказательства Кёнига; покрытие $B=Z_1\cup Y_2$, невозможные рёбра отмечены крестиком. |
| `03-cover.tex` | $C_5$: независимое множество и дополняющее его вершинное покрытие. |
| `03-gallai.tex` | Обе половины доказательства Галлаи: $M\cup F$ и лес звёзд минимального рёберного покрытия. |
| `04-tutte-set.tex` | Пример множества Татта: $\odd(G-S)=3>1$. |
| `04-cycle.tex` | Случай 2 леммы о кликах: перестройка цикла из $M_1\triangle M_2$ в путь через ребро $yz$. |
| `04-finish.tex` | Завершение доказательства Татта: клики $G-U$ и вершины $U$. |
| `05-construction.tex` | Граф $H=G$ + клика $W$ из $k$ универсальных вершин из доказательства формулы Бержа. |
| `06-stability.tex` | Три случая пути $P$ в доказательстве stability lemma. |
| `06-structure.tex` | Пример разбиения $D,A,C$ и максимального паросочетания. |
| `07-six.tex` | Задача о шести знакомых: вершина $x$ и три её соседа. |

| `10-pigeon.tex` | Принцип Дирихле в доказательстве Гринвуда–Глисона ($k=3$). |
| `10-schur.tex` | Сведение теоремы Шура к треугольникам; раскраска $1..4$ без решения. |
| `11-embed.tex` | $C_4$ внутри одноцветной $K_4$; одноцветный $P_3$ в $K_3$. |
| `12-chvatal.tex` | Экстремальная раскраска для $R(T_n,K_m)$ при $m=3,n=4$. |
| `12-step.tex` | Шаг индукции в лемме о деревьях: присоединение листа $x\in U$. |
| `13-intervals.tex` | Интервалы и их граф пересечений; глубина точки равна $\omega=\chi$. |

| `13-comparability.tex` | Транзитивная ориентация и раскраска Мирского; «сеть» — не граф сравнимости. |
